# TIP4P/Ice Water Box — Energy Minimization

A complete, reproducible example of building and energy-minimizing a **7.8 nm cubic box of pure TIP4P/Ice water** with **GROMACS 2025.4**.

## System

| Property | Value |
|---|---|
| Water model | TIP4P/Ice (Abascal et al., *J. Chem. Phys.* **2005**, 122, 234511) |
| Box | 7.8 × 7.8 × 7.8 nm (cubic) |
| Molecules | 15 993 |
| Atoms | 63 972 (OW / HW1 / HW2 / MW) |
| Density | 1.008 g/cm³ (liquid water at ~300 K) |

Force-field parameters (verified against the original publication):

| Quantity | Value |
|---|---|
| σ (OW) | 0.31668 nm |
| ε (OW) | 0.88211 kJ/mol |
| q(H) / q(M) | +0.5897 e / −1.1794 e |
| r(OH) / r(HH) | 0.09572 nm / 0.15139 nm |
| r(OM) | 0.01577 nm |

## Contents

| File | Description |
|---|---|
| `tip4p_ice.itp` | TIP4P/Ice molecule definition (SETTLE + 4-site virtual site) |
| `ffnonbonded.itp` | `[ defaults ]` and Lennard-Jones parameters |
| `topol.top` | System topology (15 993 waters) |
| `minim.mdp` | Steepest-descent minimisation parameters |
| `water.gro` | Initial configuration |
| `em.gro` | Coordinates after minimisation |
| `em.log` | Minimisation log (converged in 17 steps) |

Binary outputs (`em.tpr`, `em.trr`, `em.edr`) are **not** tracked — they are
GROMACS-version and machine dependent, and are regenerated by the commands below.

## Reproduce

```bash
gmx grompp -f minim.mdp -c water.gro -p topol.top -o em.tpr
gmx mdrun -v -deffnm em
```

## Results

| Quantity | Value |
|---|---|
| Steps to converge | 17 |
| Potential energy | −8.835 × 10⁵ kJ/mol |
| Maximum force | 762 kJ mol⁻¹ nm⁻¹ |

Verify the potential energy yourself:

```bash
gmx energy -f em.edr -o potential.xvg     # select "Potential"
```

## Notes and possible improvements

- **`emtol = 1000` is deliberately kept** so that the committed `em.gro` and
  `em.log` are reproduced exactly. For a structure that will be used as the
  starting point of production MD, tighten `emtol` to 100 (or 10) —
  this box converges in a few dozen steps either way.

- **`[ defaults ]` uses `comb-rule 2` (Lorentz–Berthelot)**, which is correct
  for TIP4P/Ice. The `fudgeLJ = 0.5` / `fudgeQQ = 0.8333` values are inherited
  from a CHARMM template and are **inactive here**: all 1-2, 1-3 and 1-4
  intramolecular pairs are excluded by SETTLE and the `[ exclusions ]` block,
  so no scaled nonbonded term is ever evaluated. A water-only topology could
  equally use `1  2  no  1.0  1.0`.

- The initial configuration is a liquid-density box, not an ice lattice. It is
  a suitable starting point for supercooling / nucleation studies but contains
  no pre-formed ice.
